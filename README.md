Данная программа реализует вычислительный эксперимент по исследованию структуры конечных групп: симметрической группы S3​, диэдральной группы D8​, группы кватернионов Q8​ и группы тэтраэдра​. С математической точки зрения, программа моделирует элементы каждой группы и операции умножения над ними, вычисляет порядки элементов, проверяет аксиомы группы (замкнутость, наличие нейтрального элемента, обратные элементы, ассоциативность) и находит все подгруппы.
